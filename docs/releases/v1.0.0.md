# v1.0.0
Breaking changes: no

## Images bumped
- First tested release: all images are pinned at the versions in `stacks/*/compose.yaml` and `worker/compose.yaml`, including the Worker (`ghcr.io/haveagitgat/tdarr_node:2.94.02`, matching `ghcr.io/haveagitgat/tdarr:2.94.02`).
- Notable majors included: Homarr v2.1.2, Maintainerr 3.30.1, Seerr v3.5.0, Radarr 6.4.4, qBittorrent 5.2.4, WUD 9.2.1, Beszel 0.21.0.

## New settings
- `GLUETUN_CONTROL_API_KEY`: empty by default; `scripts/init.sh` generates a 64-hex key. Protects every Gluetun control server route (used by Homarr's VPN integration).

## New Profiles
- None. Profiles available: backup, vo, jackett, seeding, cleanup, dashboard, monitoring, proxy, remote, extras, transcode.

## Fixes
- Template releases and Instance upgrades (`scripts/upgrade.sh`), with rollback.
- Jellyfin Android SyncPlay compatibility; Jackett updated.
- Seerr v3 library endpoints in the wire step.
- Instance and Worker share one environment contract.

## Manual steps
- None. This is the first release; there is no previous version to migrate from.
- Restart your Worker with the matching Tdarr node image after installing.
