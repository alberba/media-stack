- feat(monitoring): stop giving WUD and security-monitor Telegram credentials

- test(security-monitor): count verified updates instead of asserting messages
- feat(updates): stop sending release and security update notices to Telegram

- feat(upgrade): stop sending upgrade notices to Telegram
- feat(issue-automator): keep the delivery from breaking the webhook and document Issue Resolved
- test(issue-automator): pin the contract vector and keep the secret out of logs
