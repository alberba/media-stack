## New settings
- `SECURITY_SCAN_CRON` (default `0 6 * * *`): when the security monitor compares What's Up Docker updates with Trivy.
- `SECURITY_AUTO_UPDATE` (default `off`): opt-in verified security updates; enable with `sudo scripts/security-update.sh install`.
- Removed: `DOCKGE_STACKS_DIR`.

## New Profiles
- None. The monitoring Profile gains the security monitor; the dashboard Profile loses Dockge.

## Fixes
- Verified security alerts: Telegram notices only when an image update fixes HIGH/CRITICAL CVEs, with opt-in automatic security updates and App data rollback.
- Automatic releases and unattended upgrades for compatible updates (`sudo scripts/upgrade.sh install`, ADR-0005).
- Tdarr: selection by conservative video bitrate, output validation, hardlink protection and requeue of files released from hardlinks.
- Healthchecks across optional services and the Worker; Cleanuparr health verification.
- What's Up Docker no longer alerts for linuxserver `-lsNNN` rebuilds.

## Manual steps
1. Back up App data first (the upgrade does it with the backup Profile on). Tdarr 3 may migrate its database on first start: to go back to 2.94, restore Tdarr's App data from that backup, because rollback restores code and images only.
2. Run `sudo scripts/upgrade.sh` and confirm v2.0.0. Fill `SECURITY_SCAN_CRON` and `SECURITY_AUTO_UPDATE` when asked (Enter keeps the defaults).
3. Update every Worker to the same Tdarr version, `3.06.00`, or its node will not connect. Linux Worker: in its clone, `git fetch --tags && git checkout v2.0.0`, then `docker compose up -d` in `worker/`. Windows Worker: run `Tdarr_Updater.exe` (docs/transcode.md).
4. If you used Dockge, it is removed with the dashboard Profile update (`--remove-orphans`). Its stacks folder is left untouched.
5. Optional: `sudo scripts/upgrade.sh install` for daily unattended upgrades of later compatible releases.
